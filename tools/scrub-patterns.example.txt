# Copy this file to tools/scrub-patterns.local.txt (gitignored) and replace the placeholders with your
# own details. One rule per line: a regular expression (Python syntax, matched case-insensitively), a
# tab, then its replacement. Every pattern is also a personal-data check: a file that still matches
# after scrubbing is held back.
#

# ... and the same folder as Git Bash writes it:

# The private folder the imported files came from (it becomes lab/history in the repository):

# Your machines' names:
<your-pc-name>	<pc>
# E-mail addresses that must not be published:
