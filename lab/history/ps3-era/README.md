# PS3-era research (September to early October 2026)

The working research from the project's PS3 route (RPCS3, then Xenia for comparison), imported from
the old repository's private `RESEARCH` folder with `tools/import_lab_history.py`. It holds run
watchers and acceptance records (`JOIN…`), GPU and descriptor audits, and the tools of that period.

Left out, on top of the import's usual rules (game content, media, build outputs, keys, personal
data):
- copies of other projects' source trees (`xenia-*-src`, `rpcn-src`, `validation-source-*`, `*-source-before`);
- metadata extracted from the PS3 game updates (`ps3_updates`).

Two other folders from that period stay out entirely:
- the local RPCN server install, which holds a key pair and test credentials;
- 168,000 per-run sign-on control logs, which are raw run output.

The route itself is described in `notes/ps3-route.md`.
