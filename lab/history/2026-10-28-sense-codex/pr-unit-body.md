After a respawn, a thin heuristic position set can follow stale copies and send the walker away from the Guardian. This adds opt-in `d1-walk --native-unit`, using the existing guarded player link and the native object table. It checks the self handle, three transform copies and the link again after the read. Unit loss or a changed handle stops the route; no old-position fallback is allowed. `--memory-facing` uses two agreeing unit forward vectors in this mode. Default replay tracking is unchanged.

Validation: all 20 public Python tests pass, including six new synthetic identity/race/transform/facing controls. Native forward/backward input moved all three transform copies together; right/left input moved both forward vectors together by the expected camera angle. Post-respawn route recovery stayed blocked at a collision corner, so this remains a draft pending a successful fresh route test. These reader controls are not a full replay or enemy-kill result. No debugger, guest writes, game data or raw evidence are included.
