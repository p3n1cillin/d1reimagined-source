Runs sense47–sense51 on the owned 56578 image. Host and responder built from `main` (#72–#74). Private lists, captures and media remain outside the repository. Host-log times are UTC.

## Result

After the outro cinematic (#69), the client now leaves the black screen and shows the original end-of-mission UI: **ACTIVITY REWARDS**, **MISSION SUMMARY** ("A Guardian Rises, Old Russia, Earth", with the session time) and **ADVANCEMENT**. | Step | What the server sends | What the client does |
|---|---|---|
| 1 | A family-4 **profile delta** with field [6] (`+0x2c20`, struct `0x808017b9`) = {activity 164, completed `+0x18` = 1}, plus progression entries | `0x56e580` sees `+0x2c38` flip 0→1, passes its session checks (current activity 164) and selects the chain activity **165** (the selection record type 1, activity `0xa5`) |
| 2 | The replicated **kind-15 scoreboard** component (`0x808008D0`) with one player row: native player identity, a stat array (config `80aa3ee6`: kills at index 0, precision kills at 18, deaths at 22) and a rewards array | The UI copies the scoreboard while the lifetime phase is still below 7 |
| 3 | A sensor list with **`@phase 7`** (#73; a rowless list needs #74's padding) | `0x75e4c0` returns `phase == 7`, and the in-world handler (`0x797240` → `0x7976b0`) logs "Enter post game" and opens the screens |

## Findings along the way

- **The profile needs its progressions.** The completion path (`0x573950`) looks up two progression ids from the investment globals (`+0x166` = 117 character_level, `+0x16a` = 118 character_prestige) with `0x274970`, which returns NULL for a missing id. The tutorial profile had **zero** progressions, so the first completion push crashed the client (static `0x573a73`, run sense47). With entries for 117, 118, 124, 249 and 250 it is accepted (sense48).
- **Order matters for the scoreboard.** Once phase 7 begins the client stops copying the kind-15 component into its UI store, so the rows must arrive first (at least one sensor resend, about 10 s, before `@phase 7`). Sent after phase 7, the rows stay empty under a loading indicator (sense49).
- **The lifetime phase on its own does nothing until it lands.** A sensor-phase file whose frames carry the launch-time authority and clients did not move the phase (sense45). An `@phase 7` list under the outro's authority (13) does.
- **XP is a progression in the profile** (117 is cumulative XP: 0 = level 1, 900 = level 2, 5000 = level 3). The post-game collector seeds its samples on entry and finished before a 900-XP delta sent 8 s after phase 7 arrived, so no XP gain is shown yet (sense51: the profile holds 900, the collector shows 0/0/0, state 4).
